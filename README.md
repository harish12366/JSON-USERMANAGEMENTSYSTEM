# JavaScript Classes & JSON Practice

This repository contains JavaScript practice tasks covering **Classes, Objects, Methods, Arrays, and JSON**.

## Tasks

### Task 13.1 - User Management System

- Created a `User` class
- Used a constructor to initialize user properties
- Created class methods
- Checked whether a user is an adult
- Created multiple user objects
- Stored users in an array
- Used `for...of` to iterate through users

### Task 13.2 - Working with JSON Data

- Created JSON data
- Used `JSON.parse()` to convert JSON into JavaScript data
- Accessed and displayed object properties
- Used `for...of` to loop through users
- Used `JSON.stringify()` to convert JavaScript data back into JSON

## Concepts Practiced

- Classes
- Constructors
- `this` keyword
- Objects
- Methods
- Arrays
- `for...of` loop
- JSON
- `JSON.parse()`
- `JSON.stringify()`
- Template literals
